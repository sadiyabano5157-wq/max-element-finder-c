# Array Maximum Element Finder (C Program)

## 📌 Description
This project is a simple C program that takes 5 integer inputs from the user and finds the maximum element in the array.

## 🚀 How it works
- User enters 5 numbers
- Program stores them in an array
- It loops through the array
- Finds and prints the maximum value

## 💻 Code Logic
- Initialize array of size 5
- Take input using loop
- Assume first element as maximum
- Compare with all elements
- Update maximum if larger value is found

## 📥 Input Example
Enter array element: 10
Enter array element: 25
Enter array element: 7
Enter array element: 50
Enter array element: 30


## 📤 Output Example
maximum number is 50
